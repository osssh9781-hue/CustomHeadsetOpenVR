Mecha Lab 0.13 · Advanced Parametric Primitive

Station Primitive

단면(Profile) 하나를 지점(Station) 사슬을 따라 밀어 만드는 생성기입니다. 각 지점은 앞 구간이 끝난 방향에서 다음 구간을 시작합니다. Phase 1(생성 엔진 + 간단한 패널)을 이번에 구현했고, 아래 그림은 그 엔진이 실제로 만든 메시입니다.

엔진이 만든 실제 메시

Blender에서 생성한 메시를 단순 셰이딩으로 그린 그림입니다(Blender 렌더러가 아님). 시나리오 이름은 요청서 13절 기준입니다.

지점이 이어지는 규칙

  • 지점 0 = 시작 단면. 지점 i = 그 앞 구간: ① 꺾임(각도 · 방향 · 반경) → ② 직진 길이.
  • 반경 0 = 날카로운 접힘(Hard Fold, 접힘면은 이등분 마이터라 두께 유지). 반경 > 0 = 부드러운 꺾임, 각도를 크게 주면 Wrap/Full Wrap.
  • 꺾임은 앞 구간 끝 방향 기준(Local). 지점 1을 바꾸면 뒤 사슬 전체가 같이 돌아가지만, 뒤 지점들의 각도·폭 값은 그대로입니다. 지점마다 World 방향(절대 Yaw/Pitch)도 선택 가능.
  • 지점마다 단면 값(좌/우 폭, 위/아래 높이, 좌/우 두께, 좌/우 모서리, 릿지)을 따로 가지며, 사이 구간은 Linear · Smooth · Step으로 이어집니다.
  • 세그먼트는 자동: 꺾임 각도(Normal 8°마다 1), 비틀림, Smooth 보간이 있는 곳에만 추가. 직선 Linear 구간은 1칸.
  • 꺾임 반경이 단면보다 작아 안쪽이 겹치면 반경을 올리고 경고합니다(자가 교차 방지).

뷰포트 직접 조작 설계 (Phase 4)

숫자보다 핸들이 먼저입니다. 지점마다 아래 핸들이 뜨고, 한 번의 드래그로 한 값을 바꿉니다. 정확한 값은 핸들을 클릭하면 숫자 입력.

정해 주실 것
  1. Cut 후 처리: 지금은 살아 있는 프리미티브를 자르면 파라미터 편집을 멈추고(동결) 메시지로 알립니다. 대신 "파라미터는 살리고 Cut을 비파괴(Boolean 모디파이어)로 쌓는" 방식을 원하시면 Phase 5에서 바꿉니다.
  2. 단면 종류는 프리미티브 전체에 하나: 지점마다 단면 값은 바뀌지만 종류(라운드→박스)는 하나입니다. 지점마다 종류를 바꾸려면 Loft 방식이 따로 필요합니다.
  3. 다음 순서: 요청서 순서(2 → 3 → 4) 대신 4(지점 핸들)를 먼저 하면 지금 엔진을 바로 손으로 써 볼 수 있습니다.
