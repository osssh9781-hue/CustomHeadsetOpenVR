Mecha Lab UX 설계안

기능 추가보다 조작 흐름을 먼저 바꿉니다. 화면 하단 한 줄에서 도구·범위·빠른 명령을 다루고, 옵션은 지금 쓰는 도구 것만 보이게 합니다. 아래 내용은 구현 전 검토용 설계이며, 실제로 만들거나 실행해 본 것은 아직 없습니다.

먼저 정해 주셔야 하는 것 (설계에 영향이 큼)
  1. 단축키 정리. 지난번 요청(V = 도구 메뉴, N = 빠른 메뉴, F = Select/Move)과 이번 요청(Q 파이, Shift+Q)이 겹칩니다. 제안: Q 파이가 빠른 메뉴를 대신하고 N은 Blender 사이드바로 되돌림. V 전체 도구 메뉴, F Select/Move는 유지.
  2. 그룹의 실체. 제안: 그룹 = 빈 오브젝트(Empty) 부모 + 자식 오브젝트. Outliner와 항상 일치하고 그룹을 통째로 움직일 수 있습니다. 컬렉션은 레이어(표시/숨김/잠금 묶음)로만 씁니다.
  3. 우클릭. Substance처럼 우클릭 = 상황별 Actions 메뉴로 통일할지. 지금 Cut 도구의 우클릭(도형 팝업)은 그 메뉴의 첫 줄로 들어갑니다.
  4. 커스텀 Blender 빌드. 제안: 이번 개편은 애드온으로 진행하고, Phase 2 프로토타입에서 막히는 지점이 확인될 때만 검토 (아래 8절 비교).

1. Substance 3D Modeler에서 가져올 것 공식 문서 기준

  • Palette: 도구와 옵션이 모인 상시 패널. 고르는 도구에 따라 내용이 바뀝니다. → Mecha Lab의 상황별 옵션 카드.
  • Bottom bar: 왼쪽은 지금 작업 범위(Scope)를 보여 주고 상위 그룹/World를 눌러 빠져나옵니다. 배치 모드(Placement)와 자주 쓰는 명령(Quick Actions)도 여기 있습니다. → 하단 바의 왼쪽·오른쪽 구역.
  • Actions menu: 장면에서 우클릭하면 나오는 상황별 명령. 많은 항목이 하단 바의 Quick Actions와 같습니다. → 우클릭 메뉴 = 하단 바 오른쪽과 같은 명령.
  • Symmetry ≠ Repetition: Symmetry는 한 레이어 안에서 양쪽을 같이 만드는 파괴적 작업, Mirror Repetition은 그룹/오브젝트를 비파괴로 반대편에 복제하고 언제든 끄고 켤 수 있습니다. 축은 한 번에 하나. → Mecha Lab도 Mirror(복제)와 Symmetry(한 메시)를 별도 도구 모드로 분리.

그대로 베끼지 않는 부분: Substance는 SDF 볼륨 기반이라 Boolean·정리가 필요 없지만, Blender는 폴리곤 메시라서 Merge 후 중앙 접합 정리와 Smart Cleanup이 반드시 따라붙어야 합니다.

2. 화면 구성 MECHA LAB Workspace

하단 툴바

  • 아이콘만, 마우스를 올리면 이름 + 단축키.
  • 선택된 도구는 주황 채움. 실행 중(그리는 중)일 때는 테두리가 깜빡이지 않고 굵어짐.
  • 크기 S/M/L, 위치 하단/상단, 자동 숨김(마우스가 바닥 40px 안에 오면 표시).
  • 도구 순서는 설정에서 드래그 대신 ↑↓로 변경 (애드온 한계, 8절).

옵션 카드 (Palette)

  • 도구별 3~5개 핵심 옵션만. 나머지는 ⋯ Advanced.
  • 값은 뷰포트에서 바로 반영(라이브 프리뷰). Apply 버튼은 확정이 필요한 도구에만.
  • 선택 대상이 바뀌면 내용 자동 교체 (예: Live Mirror가 있는 오브젝트 선택 → Mirror 옵션이 Select 카드 안에 표시).

4. 도구 전환과 입력 모달 충돌 재발 방지

원칙은 하나입니다. 도구는 계속 켜져 있고, 그리기 한 번만 짧은 모달로 처리합니다. Cut을 한 번 하고 나도 Cut이 남아 있으니 다시 누를 필요가 없습니다. 도구를 바꾸면 진행 중인 획은 자동 취소되고 다음 도구는 깨끗한 상태로 시작합니다. 이 구조는 0.11.1에서 이미 Cut/Split에 적용·테스트한 방식(도구가 바뀌면 획이 스스로 끝남)을 모든 도구로 넓히는 것입니다.

5. 선택 · 그룹 · Scope 시나리오 B의 핵심

평소 클릭은 그룹 단위로 선택하고, 더블클릭하면 그 그룹 안으로 들어갑니다. 안에 들어가면 바깥 오브젝트는 흐리게 보이고 클릭되지 않으며, 하단 바 왼쪽 브레드크럼에 위치가 표시됩니다. 그룹을 풀지 않고도 안팎을 오갈 수 있습니다.

Mecha Layers 패널

  • 평소 닫힘. 상단 오른쪽 Layers ▸로 여는 팝오버/사이드바.
  • 트리 = 실제 Collection(레이어)과 Empty 그룹/오브젝트 계층. 따로 저장하는 목록이 없어서 Outliner와 어긋날 수 없음.
  • 표시·잠금·복제·그룹·해제·병합·이름 변경, 다중 선택이 뷰포트 선택과 동기화.
  • 오브젝트를 펼치면 Live Mirror / Boolean 등 Mecha 비파괴 작업이 하위 줄로 보이고 바로 수정/적용/삭제.

솔직한 한계

  • Python UI 목록은 드래그 앤 드롭이 안 됩니다. 계층 변경은 "선택한 것을 이 그룹으로" 버튼과 ↑↓로 대신합니다. 드래그가 꼭 필요하면 Outliner를 쓰거나, 소스 수정 항목(8절)이 됩니다.
  • Blender에는 "선택이 바뀌었다" 이벤트가 따로 없어서, 그룹 단위 선택은 Mecha 선택 도구의 클릭 처리로 구현합니다. Blender 기본 선택 도구로 고르면 그룹 규칙이 적용되지 않습니다.

6. 모델링 도구 통합 조작법 하나로

Cut · Split · Box Hide 공통 입력

세 도구는 같은 그리기 엔진을 씁니다. 도형(사각·타원·커브 라쏘·자유·스탬프), Alt 반전, Ctrl 중심, 더블클릭/시작점/Enter 확정, Esc 취소, 연속 작업이 셋 다 똑같습니다. 다른 것은 "결과를 어떻게 쓰느냐"뿐입니다. 이미 검증된 Cut/Split 엔진(cut_engine)은 손대지 않고, Box Hide를 같은 엔진의 세 번째 출력으로 붙입니다.

  • Box Hide: 드래그 = 영역 숨김(누적), Alt+드래그 = 일부 복원, Show All, Cap ON/OFF, Apply. Apply 전까지는 원본 메시를 건드리지 않고 Geometry Nodes 모디파이어가 "숨김 영역 목록"으로 잘라 보여 줍니다.

Mirror / Symmetry

  • Mirror (복제, 비파괴): 누르는 순간 반대편에 연결된 복제가 생깁니다. 반대편 = 원본 메시를 공유하는 오브젝트를 미러 평면 Empty 아래에 둔 것. 평면을 옮기거나 돌리면 따라오고, 그룹에도 쓸 수 있습니다. 0.11.3의 "마우스 기울인 쪽으로" 조작을 그대로 씁니다.
  • Symmetry (한 메시): 지금의 Mirror 모디파이어 방식. 추가로 Cut/Boolean을 할 때 그린 도형을 평면 반대편에도 자동으로 적용합니다.
  • Mirror → 하나로 합치기: Object Join이 아니라 실제 접합. 중앙 평면 위 내부 면 제거 → 중앙 버텍스 용접 → 노멀 재계산 → 비다양체(non-manifold) 검사. 검사를 통과하지 못하면 원본을 그대로 두고 이유를 알려 줍니다. 검은 셰이딩 줄무늬의 원인(겹친 면, 뒤집힌 노멀)을 이 단계에서 없앱니다.

Quick Place

  • 파츠가 커서를 따라옴 → ←→ 15° 회전, Shift+방향키 1° → 클릭 확정, Esc 취소.
  • S = Surface Snap 토글: 가리킨 표면에 붙고 노멀 방향으로 섭니다. 붙은 뒤에는 방향키가 노멀 축 회전, 휠 = 표면에서 거리. 다시 S = 자유 이동.
  • Blender 이동 기즈모(Select/Move)는 그대로 남깁니다.

Smart Cleanup

  • 선택한 메시/그룹에만. 단계: 중복 정점·면 → 퇴화 면 → 평평한 곳의 불필요한 엣지 정리(Sharp·Seam·베벨 루프 보호) → 가능한 곳만 삼각형을 사각형으로 → 노멀 → 유효성 검사.
  • 전/후 비교: 결과를 임시 사본으로 보여 주고 면 수·비다양체 엣지 수를 나란히 표시. 확정 전까지 원본 유지.
  • Voxel Remesh와 전체 합치기는 하지 않습니다. Boolean Apply·Mirror 합치기·레이어 병합 뒤에 같은 정리를 선택적으로 부릅니다.

  • 일반 Cube "whole object" 오류: 여전히 원인 미확정. 0.11.2 진단 메시지 결과를 받으면 Phase 2 전에 먼저 해결합니다.
  • Radial Array 충돌: crash 로그 대기 중. 하단 바 버튼은 모달이 아닌 기즈모라서 새 충돌 경로를 만들지 않는 쪽으로 설계했습니다.
  • Blender 기본 기능과의 충돌: 새 단축키·우클릭·하단 바는 MECHA LAB Workspace에서만 켜지고, 다른 Workspace는 Blender 그대로입니다.
