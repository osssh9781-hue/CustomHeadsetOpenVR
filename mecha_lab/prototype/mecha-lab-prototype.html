Esc 우선순위 (위에서부터 하나만 실행)

  1. 열린 메뉴(Q 파이·우클릭) 닫기
  2. 그리는 중이면 획 취소 (도구는 그대로)
  3. Quick Place 중이면 배치 취소 (원래 자리로)
  4. Select에서 그룹 안이면 한 단계 밖으로
  5. 모델링 도구면 Select로 (라이브 결과는 유지)
  6. Select면 선택 해제

화면 맨 아래 상태줄에 지금 Esc가 무엇을 할지 항상 표시합니다.

전역 키

  • Q 전체 도구 파이 (누르고 방향으로 밀어 떼기, 또는 눌렀다 클릭)
  • Shift+Q Select ↔ 마지막 모델링 도구
  • F Select 바로 가기 · C Cut · B 즉시 Boolean Difference (기존 유지)
  • V 비움: Q 파이와 같은 메뉴라 중복. 필요하면 나중에 다시 지정
  • N Blender 사이드바 (Mecha가 쓰지 않음)
  • G Quick Place (Mecha Select 도구 안에서만, Blender의 G 대신) — 결정 필요
  • Ctrl+G 그룹 · Ctrl+Shift+G 해제 · Shift+D 복제 · Del 삭제
  • Ctrl+Z / Ctrl+Shift+Z 되돌리기 / 다시 (도구·도형은 되돌아가지 않음)

무엇이 만들어졌고 무엇이 검증됐나

"1046개 자동 테스트"는 Linux에서 화면 없이 돌린 Blender(bpy 5.0.1) 테스트입니다. 대부분 기하 계산과 가짜 마우스 이벤트로 도는 로직을 확인합니다. 실제 창에서 마우스로 누르는 동작, 그려지는 화면, Windows Blender 5.0.2에서의 동작은 하나도 확인하지 못했습니다.
