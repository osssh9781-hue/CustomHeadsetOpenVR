# Mecha Lab v0.7.1 — 선택 모드 단축 조작 및 직교 뷰 잠금

**기준:** Claude Code가 작성한 Mecha Lab v0.7.0. 기존 Cut/Split/Mask/Boolean/Mirror 등은 보존.

## 1. 뷰포트 좌클릭 3회 → 선택 도구
- Cut / Split / Mask의 도형 입력 중, 뷰포트 **거의 같은 곳을 빠르게 세 번** 누르면 `builtin.select_box`로 전환합니다.
- 세 번 클릭은 짧은 시간·약 12px 이내 같은 위치만 인식합니다. 서로 다른 위치를 찍으며 윤곽을 그리는 작업은 오작동을 줄이도록 했습니다.
- 그리다 만 획이 있다면 적용하지 않고 버립니다. 이미 완료한 컷은 유지합니다.
- Blender는 세 번 클릭 이벤트를 기본 제공하지 않기 때문에 애드온이 각 마우스 다운을 추적합니다. 실제 Windows 5.0.2 GUI의 시간 차이나 입력 이벤트는 추가 검증이 필요합니다.
- **기존 더블클릭 = 컷 확정**도 유지됩니다. 즉 세 번째 클릭 때 선택 도구로 복귀합니다.

## 2. 직교(투시 없는) 뷰 잠금 버튼
- MECHA LAB 작업공간의 공통 Shape 팔레트에 **Ortho** 버튼 추가.
- 오른쪽 Mecha Lab 패널의 최상단과 `Workspace & Hotkeys`에도 동일 버튼 배치.
- ON: 현재 Workspace 내 3D 뷰를 직교(ORTHO)로 바꾸고, Blender의 자동 원근 복귀가 발생해도 다시 직교로 되돌립니다.
- OFF: 일반 원근(PERSP) 뷰로 돌아갑니다.
- 주기적 검사는 약 0.17초마다 수행되며 다른 작업공간이나 Blender 전역 Navigation 환경설정을 변경하지 않습니다.

## 3. 코드 검사 / 실행 테스트
- Python 문법 검사 통과.
- Linux headless `bpy 5.2.2`에서 애드온 등록/해제, 3회 클릭 로직, 3회 클릭 범위 밖 무시, 중복 이벤트 제거, 원근 ↔ 직교 잠금 및 자동 복귀, 선택 도구 복귀를 직접 테스트.
- Blender **5.0.2 Windows GUI 입력 자체는 미검증**. 5.0.2에서 오류가 나면 Console Traceback을 전달 바랍니다.
