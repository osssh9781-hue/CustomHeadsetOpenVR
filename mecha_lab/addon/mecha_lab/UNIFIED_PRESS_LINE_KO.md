# 메카닉 랩 0.24.100 — Press / Line 통합

기존 **Press Cut 툴** 아이콘에서 다음 제스처를 사용할 수 있습니다. 기존 Cut, Base Mesh, Press 엔진을 재사용합니다.

- **왼쪽 마우스로 그리기:** Line Cut. 기존 Cut의 선택 대상 및 절단 설정을 사용합니다.
- **Alt + 그리기:** Base Mesh Line. 기존 Base Mesh 프로필과 두께/높이/Attach Ends 설정을 사용합니다.
- **왼쪽 마우스를 누르고 유지:** Press Cut. 누른 시간에 따라 더 깊게 들어갑니다.
- **Alt + 누르고 유지:** Grow Press. 별도 메쉬가 자라나는 기존 기능입니다.
- **Shift + 드로잉:** 기존 스탬프 모양 그리기(변경 없음).
- **[ / ]:** 기존 프레스 스탬프 크기, **R:** 회전(변경 없음).

드래그 인식 거리 **12px**, 홀드 인식 대기 **0.18초**입니다. 빠른 클릭도 얕은 프레스로 적용됩니다. 마우스를 누른 채 움직여 12px 이상 이동하면 그리기로 분류되므로, 길게 그리는 동안 홀드로 오인하지 않습니다. 반대로 0.18초 이상 움직이지 않은 뒤 드래그하면 이미 프레스가 시작되었을 수 있습니다.

**Line Width**: N 패널 > Mecha Lab > Press Cut 설정의 **Draw Line Width**. 라인 컷과 베이스 메쉬 라인에 공통 사용합니다. Line Caps와 Taper는 원래 Brush 옵션을 따릅니다.

기존 별도 Cut / Base Mesh 도구도 그대로 유지했습니다. Blender 5.3은 Python 구문 검사만 완료했으며, Blender GUI 내 실행 테스트는 수행하지 못했습니다.
