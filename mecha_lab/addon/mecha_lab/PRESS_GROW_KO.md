# Mecha Lab 0.24.98 — Alt 프레스 생성

프레스 컷 도구에서 **Alt를 먼저 누른 채 왼쪽 마우스 버튼을 길게 누르세요.**
현재 스탬프 모양의 별도 메쉬가 표면에서 화면 쪽으로 자라납니다.
Alt 여부는 클릭하는 순간 결정됩니다. 도중에 Alt를 놓아도 생성 모드를 유지합니다.

- 기본 클릭: 기존 Cut / Split 동작.
- Alt + 왼쪽 버튼 유지: 생성. 오래 누를수록 높아집니다.
- 왼쪽 버튼 놓기: 확정하고 생성한 메쉬 선택.
- 누르는 중 Esc / 오른쪽 버튼: 이번 생성 취소.
- Shift + 그리기 / Shift + Alt: 기존 스탬프 그리기 / 빼기 유지.
- Start: 시작 높이, Speed: 초당 증가량, Max: 최대 높이. 원본 크기에 대한 비율입니다.
- 밑면은 평평한 한 평면이며, 스탬프 아래에서 샘플링한 가장 깊은 표면보다 원본 크기의 1%만큼 더 안으로 들어갑니다. 누르는 동안 밑면은 고정되고 윗면만 자랍니다. 얇은 원본에서는 밑면이 뒷면을 통과할 수 있습니다.
- 생성 방향은 화면 쪽(시선 반대 방향)입니다. 각 점의 표면 노멀 방향은 아닙니다.
- 생성은 항상 표면을 따릅니다. Floor의 Level/Flat은 기존 컷에 적용됩니다.
- Curve 설정은 돌출면에 적용됩니다. 원본 재질 슬롯을 복사합니다.
- 별도 오브젝트이므로 원본과 용접/불리언 합치기를 하지 않습니다.
- 원본의 미러 모디파이어와 컷 전용 Edge Finish는 생성물에 자동 복사하지 않습니다.

설치: 기존 애드온을 이 ZIP으로 업데이트하고 Blender를 재시작하세요.
문법 검사와 독립 로직 검사를 통과했습니다. Blender 실행 환경이 없어 실제 UI 조작 및 Blender 내부 삼각분할 검증은 수행하지 못했습니다.
