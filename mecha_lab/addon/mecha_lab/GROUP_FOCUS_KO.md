# MECHA LAB 0.24.101 — 그룹 포커스 / 자동 그룹 편입

이번 버전은 0.24.100 Unified Press + Line 위에 그룹 조작을 개선했습니다.

## 뷰포트 선택 방식 (Select / Move 모드에서만)

- **한 번 클릭**: 그룹 안의 부품을 누르면 가장 바깥 그룹 핸들이 선택됩니다. 부품을 따로 선택하기 위해 클릭을 여러 번 반복할 필요가 없습니다.
- **더블클릭**: 선택된 그룹 안으로 진입해 개별 부품을 선택하고 수정합니다.
- **중첩 그룹**: 상위 그룹 안에서는 직접 속한 부품은 개별 선택, 하위 그룹 부품을 클릭하면 그 하위 그룹이 선택됩니다. 하위 그룹을 더블클릭하면 한 단계 더 안으로 들어갑니다.
- **한 단계 나가기**: Groups 또는 Layers의 Exit/Up 버튼을 누르면 한 단계 위의 그룹으로 돌아갑니다. 가장 바깥 그룹에서는 전체 편집 모드로 복귀합니다.
- **Shift/Ctrl/Alt 클릭 및 다른 드로잉 도구**: 원래 조작을 유지합니다. 뷰포트 그룹 선택은 Select / Move 모드에서만 작동합니다.

## 자동 그룹 편입

- 그룹 내부 편집 중 새로 만들어진 가시적인 **Mesh, Curve, Surface, Text** 오브젝트는 현재 그룹에 자동 편입됩니다.
- 새 오브젝트는 그룹의 Collection으로 이동하고, 그룹 핸들의 자식이 됩니다. 월드 위치·회전·크기는 유지합니다.
- 기존 오브젝트, 다른 그룹에 속한 오브젝트, 미리보기 보조 오브젝트, 숨겨진 리소스는 강제로 가져오지 않습니다.
- 그룹 해제 시 원래 컬렉션으로 되돌릴 수 있도록 생성 전 컬렉션 기록을 남깁니다.
- 자동 편입은 최대 약 0.3초 후에 반영됩니다(간헐적 백그라운드 확인). 생성 직후 바로 조작하기 전에 소속이 반영됐는지 확인해 주세요.

## 설정

3D View > Sidebar (N) > Mecha Lab > Groups에서

- **Click Select / Double-click Enter** — 뷰포트 그룹 클릭 조작 활성화/비활성화
- **Auto-add New Parts in Group** — 새 오브젝트의 자동 그룹 편입 활성화/비활성화

기본값은 둘 다 켜짐입니다. 새 기능과 기존 작업 방식 사이에 충돌이 있으면 각 옵션을 꺼서 원래 방식으로 사용할 수 있습니다.

## 테스트 권장

새 .blend 파일에서 큐브 2개 그룹 생성 > 메쉬 클릭해 그룹 선택 > 더블클릭 진입 > 다른 큐브 생성 > 큐브가 그룹을 따라 움직이는지 확인 > Exit > 중첩 그룹으로 반복.

**개발 검증**: Python 구문 검사, 구조 단위 테스트, ZIP 무결성 확인. Blender 5.3 Beta의 실제 3D 뷰포트 런타임 동작은 아직 확인하지 못했습니다.
