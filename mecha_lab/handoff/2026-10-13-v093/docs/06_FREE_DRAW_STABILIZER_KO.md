# F08 — Free Draw 스트로크 안정화 (2026-10-13 09:50 최종 추가)

## 사용자 의도
현재 Free Draw 사용 중 손이 떨리거나 빠르게 이동하면 굴곡이 생긴다. ZBrush의 Lazy Mouse처럼 **실제 드로잉 경로가 마우스를 조금 늦게, 천천히, 완만하게 따라오는 드로잉 어시스트**가 필요하다. 단지 획이 끝난 후 한 번 매끈하게 후처리하는 기능으로 대체하지 말 것. 사용자가 슬라이더로 반응과 부드러움을 조절해야 한다.

## 기능/조작
- **Free Draw 공통 Shape/Brush 팔레트**의 도구 공통 설정으로 노출. Cut / Split / Base Mesh에서 같은 Stabilizer 로직을 재사용. Mask는 최신 사용자 요청대로 UI에서 숨긴 상태를 유지하며 다시 활성화하지 말 것. 나중에 Mask를 복구한다면 동일 로직 재사용 가능.
- **Enable Stabilizer (ON/OFF)**: 기본 OFF (예전 입력 조작·속도 유지). ON일 때 미리보기(실제 보정된 선)와 최종 생성 형상이 일치해야 함.
- **Smoothing Strength (0..100%)**: 필터링 정도. 낮으면 손을 빠르게 따라오고 높으면 매끄럽지만 느리게 따라옴. 정확한 함수는 구현자 선택이나 샘플링 주기와 무관하게 체감 반응이 일관적이어야 함 (예: dt-aware exponential smoothing).
- **Lazy Radius (0..80 px, 사용자 조절 범위 확장 가능)**: 움직임이 작은 동안에는 선이 정지하고, 커서가 지연 원 밖으로 나갈 때부터 실제 그려지는 점이 원 경계를 따라 이동하는 ZBrush식 지연. 시각적 가이드 원/커서-추종 점 연결선은 ON 상태에서 옵션.
- **Stroke Spacing (예: 1..20 px)**: 보정된 곡선에서 정점 생성 간격. 불규칙한 이벤트 간격·매우 느린 움직임에도 지나친 중복 포인트 방지. 기존 Free Draw 스페이싱 옵션이 있으면 새 프로퍼티 중복 생성하지 말고 재활용.
- **Follow Speed** (선택적): Strength와 지나치게 중복된다면 새 슬라이더로 만들지 말고 기존 Strength로 반응 속도도 제어. UI 슬라이더 남발보다 의미 명확성이 우선.
- **Stroke Smoothing Preview**: 커서 실제 위치와 안정화된 경로를 구분해 보여줌; Blender 5.0.2 GUI에서 프레임/이벤트 간 끊김, draw handler 및 timer 정리를 검증.
- 종료(마우스 떼기): 사용자 입력의 최종 위치가 의도치 않게 누락되지 않도록 필요시 안정화 경로가 지연 지점까지 자연스럽게 따라온 뒤 완성. 마우스 떼자마자 아주 긴 직선으로 마지막 위치에 순간 점프하거나 이중 점을 만들지 말 것. 자유형 Cut / Split / Base Mesh의 자동 폐곡선 마감 및 Ctrl+Z와 양립.

## 반드시 피할 부작용
- Lasso(포인트로 찍는 직선), Curve Lasso(베지어 점 편집), Rectangle, Circle, Ellipse, PNG shape preset, 독립 Curve Tool을 멋대로 바꾸지 않는다. 보정이 필요한 건 Free Draw의 연속 MOUSEMOVE 기반 path input이다.
- 실시간 smoothing 때문에 처리 경로가 늘어나 자기교차나 매우 짧은 에지, 불린 비매니폴드 결과가 생길 경우 정리/거부 메시지 제공. 사용자 의도한 큰 코너까지 과도하게 둥글게 만들지 않도록 OFF/0%/0px 상태 정확히 기존 동작과 동일.
- 샘플 좌표는 viewport 픽셀 기준의 필터를 적용하되, 실제 Cut은 기존 view-projection/3D 깊이 알고리즘을 그대로 사용.
- 끝점의 이중 추가, 닫힘 실패, Alt+짧은 클릭과 Alt+드래그 구분, 임의 위치 더블클릭 완결, 모달 내 UI 입력 pass-through를 모두 유지.

## 수용 테스트
1. OFF / 0% / 0px에서 v0.9.3 기존 Free Draw 경로와 거의 동일한 결과, 비활성 영향 없음.
2. 동일한 높은 주파수의 흔들리는 커서 이벤트 입력에 Strength 증가 → 잔진동 감소, 입력 지연 증가를 수치/영상으로 증명.
3. Lazy Radius 증가 → 커서가 원 안에 있을 땐 스트로크 점 고정; 바깥에서는 부드럽게 추종.
4. 느리게 직선·급커브·빠른 지그재그·마지막 짧은 획, Shift/Alt 보조키, 여러 연속 획, MMB 뷰 회전 통과 확인.
5. Cut/Split/Base Mesh 별 후속 메시 생성 결과 매니폴드, Undo 1 step, 실패 rollback; 큰 고밀도 오브젝트에서 뷰포트 성능 저하 방지.
6. GUI에서 설정을 드로잉 전에 변경하고, 설정 UI 클릭 시 툴이 입력을 독점하지 않는지 검사.
