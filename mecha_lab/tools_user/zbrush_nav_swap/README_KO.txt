ZBrush 뷰포트 조작에서만 Shift 와 Alt 를 바꾸기
================================================

하는 일 (ZBrush 창이 앞에 있을 때만):
  빈 캔버스에서 Shift + 끌기  ->  화면 이동 (원래 Alt 가 하던 것). 끄는 중에 Shift 를 떼면 확대 / 축소.
  빈 캔버스에서 Alt   + 끌기  ->  회전을 정면 / 옆면에 맞춤 (원래 Shift 가 하던 것)
  오른쪽 버튼(펜 옆 버튼)으로 끌 때도 같음.

그대로인 것:
  모델 위에서 칠할 때의 Alt(반대로) 와 Shift(스무스). 다른 프로그램.

설치 (한 번만):
  1. AutoHotkey v2 설치 (무료): https://www.autohotkey.com
  2. 이 폴더의 install.bat 을 더블클릭.
     -> 지금 바로 켜지고, 윈도우를 켤 때마다 자동으로 켜짐.
        (zbrush_nav_swap.ahk 를 윈도우의 "시작프로그램" 폴더에 복사함. 그 밖의 설정은 건드리지 않음.)
  3. 배경색 알려 주기 (한 번만): ZBrush 에서 커서를 빈 캔버스 위에 두고 Ctrl + Alt + B.
     배경이 위아래로 색이 달라지므로 캔버스의 위쪽 / 가운데 / 아래쪽에서 한 번씩 (세 번) 누름.
     -> "빈 곳" 과 "모델" 을 화면 색으로 구분함. 색은 %APPDATA%\MechaLab\zbrush_nav_swap.ini 에 저장되어 계속 유지.
     잘못 눌렀으면 Ctrl + Alt + N 으로 지우고 다시.

끄기 / 지우기:
  uninstall.bat 더블클릭. 아직 켜져 있으면 시계 옆 초록색 H 아이콘을 우클릭 -> Exit.

알아 둘 것:
  - 빈 곳 / 모델 구분은 커서 아래 화면 색으로 함. 모델 색이 배경색과 거의 같은 부분(회색 재질의 어두운 곳 등)에서는
    모델 위인데도 빈 곳으로 잘못 볼 수 있음. 그럴 때는 ZBrush 의 Document 에서 배경색을 모델과 다른 색으로 바꾸고
    Ctrl + Alt + N -> Ctrl + Alt + B 로 다시 알려 주면 됨.
  - ZBrush 배경색을 바꾸면 다시 알려 줘야 함.
  - 펜(타블렛)으로 끌 때 되는지는 확인하지 못함.
  - Windows 에서 실행해 보지 못하고 만든 파일임.
