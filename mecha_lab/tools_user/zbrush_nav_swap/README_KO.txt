ZBrush 뷰포트 조작에서만 Shift 와 Alt 를 바꾸기
================================================

하는 일 (ZBrush 창이 앞에 있을 때만):
  Shift + 오른쪽 버튼 드래그  ->  화면 이동 (원래 Alt 가 하던 것)
  Alt   + 오른쪽 버튼 드래그  ->  화면 회전을 정면 / 옆면에 맞춤 (원래 Shift 가 하던 것)

그대로인 것:
  브러시의 Alt(반대로) 와 Shift(스무스) - 왼쪽 버튼 / 펜 끝으로 칠할 때는 바뀌지 않음.
  다른 프로그램.

설치 (한 번만):
  1. AutoHotkey v2 설치 (무료): https://www.autohotkey.com
  2. 이 폴더의 install.bat 을 더블클릭.
     -> 지금 바로 켜지고, 윈도우를 켤 때마다 자동으로 켜짐.
        (zbrush_nav_swap.ahk 를 윈도우의 "시작프로그램" 폴더에 복사함. 그 밖의 설정은 건드리지 않음.)

끄기 / 지우기:
  uninstall.bat 더블클릭. 아직 켜져 있으면 시계 옆 초록색 H 아이콘을 우클릭 -> Exit.

알아 둘 것:
  - 오른쪽 버튼(펜 옆 버튼)으로 화면을 움직일 때만 바뀜. 빈 곳을 왼쪽 버튼으로 끌어서 움직이는 방식은
    브러시와 구분할 수 없어서 바꾸지 않음.
  - Windows 에서 실행해 보지 못하고 만든 파일임.
